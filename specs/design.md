# HLFSR-64 技术规格书

> 8×8×8 矩阵 (512b) · 8×64b Galois LFSR · mask-multiply 混合 · 面交叉反馈 · 面隔离批处理 · 2.03 GB/s

## 1. 设计哲学

HLFSR-64 是一个**反馈流密码核心**——内部状态同时作为数据源和控制源。每步从矩阵读取一字节经乘法映射为 64 位奇数乘子（$\mathsf{mk} = \mathsf{mask} \cdot K_2 \mid 1$），全部 8 条 LFSR 无条件异或后经 $\mathsf{mk}$ 和 $K_1$ 级联相乘产生输出，输出低 16 位经 $K_2$ 乘法后回填矩阵（低 8 位回填当前面、高 8 位交叉注入相邻面）。这种"读自身→生成乘子→乘法混合→回填→写自身"的闭环创造了不可预测的状态动力学。

四个核心洞察驱动了设计：

1. **乘性混合是天然 S-Box**：64×64 模乘（奇数→双射）在 GF(2) 上产生 ~32 次布尔函数，单条 `imul` 指令替代了查表或复杂逻辑
2. **掩码乘法替代位选通**：8 位掩码经乘法映射为 64 位奇数乘子，每步产生不同的置换函数（256 种），消除了 per-bit 条件选择
3. **面隔离使批处理可行**：`face = idx & 7` 确保连续 8 步访问 8 个不同面，读写无冲突，8 步可批量预解码
4. **Galois 比 Fibonacci 快 60%**：消除 parity 折叠，只剩移位+sbb+xor 三条指令

## 2. 顶层参数与密码学意义

| 参数 | 值 | 设计理由 |
|------|-----|---------|
| 矩阵 | 8×8×8 = 512 bits | 面积与状态空间平衡点 |

| 输出 | 64 bits/step | 匹配通用 CPU 字宽 |

| 回填常数 | K₂ = 0xBF58476D1CE4E5B9 | SplitMix64, 16b 面交叉反馈 |
| 吞吐 | 2.03 GB/s | 纯 C++14, GCC -O3 |

## 3. 坐标编码与面隔离原理

```
face = idx & 7           // 低 3 位决定面: 连续 8 步面号不重复
row  = (idx >> 3) & 7    // 面内行: 8 步完成 64 步遍历 8 行
col  = (idx >> 6) & 7    // 行内列: 64 步变化一次，ROL8 移位量
addr = face * 8 + row    // 字节地址 (0–63)
```

**面隔离的保证**：步 t 写 面(face_t)，步 t+i 读 面(face_{t+i})。由于 face = idx & 7 且 idx 每步 +1，对于 1 ≤ i ≤ 7，总有 face_{t+i} ≠ face_t。因此步 t 的写回不会破坏步 t+1..t+7 的读取。这是**8 步批处理无 RAW 冲突的数学保证**。

**完整的 idx 周期**：512 步遍历所有 (face, row, col) 组合。每 8 步修改全部 8 个面各一次，每 64 步修改全部 64 个矩阵字节，每 512 步回到相同坐标。

## 4. 每步操作的密码学功能

```
步骤                         密码学功能
───                         ──────────
1. 坐标解码                 利用 idx 的 3+3+3 结构提供确定性地址流
2. mask = matrix[addr]      读矩阵: 状态决定乘子
3. p=col, curbit=(byte>>col)&1  curbit 提供全局翻转，p 提供行内扩散
4. Galois LFSR 1-step ×8    线性状态演化，周期 2^64−1
5. vx = ⊕ LFSR[i] (全8条)   无条件全异或，无分支
6. vx ^= ROTL33(vx)         自旋转打破 LSb 线性依赖
7. mk = (mask·K₂) | 1       掩码→64b 奇数乘子, mask=0 → mk=1
8. raw = vx × mk × K₁       级联乘法: 进位链将度提升到 ≈32
9. output = raw ^ curbit^64  输出翻转
10. fb = (raw & 0xFFFF) × K₂ 16b 反馈
11. matrix[addr] ^= fb[0:7]  低 8 位回填当前面
12. matrix[addr] = ROTL8(addr,p) 行移位扩散
13. matrix[(face^1)*8+row] ^= fb[8:15] 高 8 位交叉注入相邻面
14. idx++                    遍历全状态
```

### 4.1 掩码乘法的动态组合性质

每步从矩阵读取 1 字节，经乘法映射为 64 位奇数乘子 $\mathsf{mk} = (\mathsf{mask} \times K_2) \mid 1$。全部 8 条 LFSR 无条件参与异或，无需逐位选通。256 种不同的 mask 值产生 256 种不同的乘子，每一步使用不同的 GF(2) 上度 ≈32 的置换函数——组合函数动态化由乘法完成，而非位选择。

### 4.2 mask=0 的处理 (1/256 概率)

mask=0 时 $\mathsf{mk} = 0 \mid 1 = 1$（恒等乘子）。$\mathsf{raw} = v_x \times 1 \times K_1 = v_x \times K_1$，自然退化为无条件异或后的单乘混合。无需分支、无需 ct_eq8、无需额外状态。

### 4.3 乘性混合 的代数深度

`vx → vx × mk × K₁` 在 GF(2^64) 上是级联双射（两个奇数乘子）。$v_x$ 进入乘法前先经 $\mathrm{ROTL}_{33}$ 自旋转混合，打破 LSb 的纯线性依赖（每位依赖 $v_x$ 的两个不同位）。级联乘法的进位链将代数度提升到 ≈32，是 HLFSR 抵御代数攻击的核心屏障。

## 5. 初始化与密钥材料

```
init(key_material[64], idx_init(u16)):
  1. 拒绝全零种子
  2. 解析 km → 8 × u64: w[0..7]
  3. 三乘积自混合: mm[i] = w[i] × ROTL23(w[i+1]) × ROTL41(w[i+2])
                    ml[i] = w[i+4] × ROTL23(w[i+5]) × ROTL41(w[i+6])
  4. 8×8 MDS over GF(2^8): 逐列 circulant [2,3,1,1,1,1,1,1] 混合 mm 和 ml
  5. memcpy(matrix, mm); memcpy(lfsr, ml)
  6. 64 步预热 (不再需要 512)
```

**阶段1: 三乘积自混合** — 24 词池 (w + ROTL23(w) + ROTL41(w))。每项 = 来自三组不同旋转量的 3 词乘积。环乘法使逆向求解 mm[i]→w[*] 不可行 (碰撞率 0/10⁷)。但项间依赖稀疏 (3/8 词)。开销: ~50 指令, ~50ns。

**阶段2: 8×8 MDS** — GF(2^8) 上的 AES MixColumns 8×8 拓展版。对 mm 和 ml 的按字节列施加 circulant MDS [2,3,1,1,1,1,1,1]。将阶段1 的局部依赖扩散到全部 8 词 (分支数 9 → 单列变化 8 列全变)。开销: 256 次 xtime + XOR, ~200ns。

**阶段3: 64 步预热** — 运行 64 步密码丢弃输出。矩阵完整遍历 1 轮，LFSR 各移位 64 次。自混合+MDS 已将差分雪崩提升至 50%、零差率降至 0.0%，仅需 64 步精调。预热减少 87.5% (512→64)。

## 6. Galois LFSR 实现

```
Fibonacci (旧): parity(tap_bits) → popcnt 指令
Galois (新):    s' = (s<<1) ^ (poly & -(s>>63))
                移位 + sbb + xor = 3 指令/LFSR

Fibonacci 需要水平折叠 64 位→1 位 (popcnt)，Galois 仅需提取 MSB 并广播为掩码。
每条 LFSR 节省约 60% 指令，8 条合计从 8×popcnt→8×sbb，批处理中效果放大。
```

**多项式**：8 个 68 次本原多项式 (权重 13–15)，随机采样 + 不可约验证 + 本原验证。Galois 配置下与 Fibonacci 等价（周期相同，输出序列为线性变换），但推进效率更高。

## 7. 批处理实现

```
keystream 大循环：每次处理 64 字节 (8 步 × 8 bytes)

1. 预解码 8 个 mask/p/curbit/邻面地址 (从当前矩阵，面隔离保证无依赖)
2. 8 次 LFSR 推进 + 全异或 + vx 自旋转 + mask 乘子 + 级联乘法 (串行：LFSR 状态有步间依赖)
3. 8 次矩阵回填 ×2 (每步写 2 个面地址：当前面 + 邻面，面隔离保证无冲突)
```

尾部不足 64 字节回退单步。预解码消除了 8 次 `next()` 函数调用开销和地址计算的重复。面交叉反馈每步写两个面（当前面和相邻面），面隔离恒保证 $\mathsf{face} \oplus 1 \neq \mathsf{face}$，批处理内无 RAW 冲突。

## 8. 版本演进与关键设计决策

| Ver | 代号 | 核心改进 | MB/s | NIST | 决策 |
|-----|------|---------|------|------|------|
| V1 | ISA | 16 指令机 | 115 | — | 过于复杂 |
| V2 | MF | 16×16 矩阵 | 238 | — | mask 选通优于 ISA |
| V3 | MV | 批处理 | 266 | — | 面隔离使批处理可行 |
| V4 | V8-Fib | 8×8×8 | 271 | — | V1→V8 的 10 倍速来自砍掉不必要的复杂度 |
| V5 | Galois | Galois LFSR | 358 | — | shift+sbb 替换 popcnt |
| V6 | Mask16 | 16b mask | 790 | — | 掩码表替换 ct_eq8×48 |
| V7 | Mask8 | 8b mask | 790 | — | mask→1 字节 |
| V8 | V8-Mask | 8 LFSR | 1200 | 49/50 | 8=8：矩阵行=掩码位 |
| V9 | V9-Aux | +1 aux LFSR | 1220 | — | 废弃（idx&7 更简洁） |
| V10 | V10-Idx | mask=0→idx&7 | 1240 | 50/50 | NIST 首次满分 |
| V11 | V11-Uni | 三乘积+MDS+64 | **1360** | **98/100** | 位选通最终版 |
| V12 | V12-MM | mask-multiply+ROTL33+面交叉 | **2030** | **100/100** | 乘法替代位选通，消除 SIMD 阻塞点 |

**核心教训**：V1→V11 的性能翻倍来自砍掉不必要的复杂度（指令 ISA、ct_eq8、aux LFSR）。V12 的质变来自**改变选通范式**——乘法替代位选通，消除 per-bit 条件操作，编译器自动向量化。代数度 ≥24，$2^{30}$ 对线性深测通过检验。

## 10. 与 ChaCha20 的设计对比

| 维度 | HLFSR-64 V12 | ChaCha20 |
|------|-------------|----------|
| 非线性源 | 级联模乘 (vx×mk×K₁, 2 imul) | ADD+XOR+ROL (20 轮) |
| 状态大小 | 512+512+9=1033b | 512b (16×32) |
| 每步工作 | 8 LFSR + 全 XOR + vx 自旋转 + 2 imul + 16b 回填 | 80 次 ADD+XOR+ROL |
| 纯软件吞吐 | 2.03 GB/s (-O3 自动向量化) | ~550 MB/s (C), ~1.76 GB/s (SIMD) |
| SIMD 友好 | 是 (全异或自动向量化) | 是 (4 列独立) |
| 反馈 | 面交叉 (16b K₂ 回填, 双面注入) | 否 (计数器增量) |
| 标准化 | 实验性 | RFC 8439, TLS 1.3 |
