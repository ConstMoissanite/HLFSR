# HLFSR-64 V8-Mask 基底 LFSR 多项式

## 概述

8 条 64 位 Galois LFSR，各使用一个 64 次本原多项式。当前使用权重 7 多项式（待升级至 12–15）。

## 当前多项式

```
static const u64 POLY[8] = {
    0x0054010000020001ULL,  // x^64 + x^54 + x^52 + x^50 + x^40 + x^17 + 1
    0x0080000004200083ULL,  // x^64 + x^55 + x^26 + x^21 + x^7  + x    + 1
    0x0100000020040481ULL,  // x^64 + x^56 + x^29 + x^18 + x^10 + x^7  + 1
    0x0000088040008005ULL,  // x^64 + x^43 + x^39 + x^30 + x^15 + x^2  + 1
    0x0804000004200101ULL,  // x^64 + x^59 + x^50 + x^26 + x^21 + x^8  + 1
    0x0000900008400009ULL,  // x^64 + x^47 + x^44 + x^27 + x^22 + x^3  + 1
    0x8000110004001001ULL,  // x^64 + x^63 + x^44 + x^40 + x^26 + x^12 + 1
    0x2000000000820141ULL,  // x^64 + x^61 + x^23 + x^17 + x^8  + x^6  + 1
};
```

## 升级计划

从 16 条改 8 条后，每条 LFSR 被选中的平均概率从 3/16≈19% 升到 mask Hamming weight/8≈50%（8 位随机掩码期望 4 位为 1）。单条 LFSR 参与输出的频率提高，需要更高权重多项式补偿线性结构暴露。

目标：使用 `tools/polyselect.cpp` 筛选 8 个权重 12–15 的 64 次本原多项式。生成工具已就绪，只需运行 `polyselect` 并替换上表。
