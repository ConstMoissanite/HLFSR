# HLFSR-64 V10-Idx 安全性分析

## 1. 威胁模型

| 维度 | 假设 |
|------|------|
| 攻击者能力 | 已知/选择明文 (标准流密码) |
| 密钥 | 256 位均匀随机 (外部 KDF) |
| Nonce | 同 Key 不重复 |
| 侧信道 | 时间侧信道 (常数时间缓解) |

## 2. 状态空间

| 组件 | 位数 | 结构 |
|------|------|------|
| matrix | 512 | 8 面 × 8 行 × 8 位 |
| 8×64-bit LFSR | 512 | Galois, 权重 13–15 本原多项式 |
| idx | 9 | 0–511 |
| **合计** | **1033** | |

初始化输入 98 字节 (64 matrix + 32 lfsr_seed + 2 idx = 784 位)，由外部 256 位密钥经 KDF 派生。总状态空间 2^1033 远超 2^256，穷举密钥为最优通用攻击。

## 3. 非线性源

### 3.1 64×64 模乘

`raw = vx × K`，K = 0x9E3779B97F4A7C15。奇数 → GF(2^64) 上双射。在 GF(2) 上乘法进位链产生约 32 次代数度。LFSR 输出为线性 (度 1)，经乘法后输出函数度 ≈ 32。

### 3.2 掩码反馈闭环

```
matrix[face,row] → mask → LFSR XOR ×K → raw[7:0] → matrix[face,row] ← ROL8(p)
```

矩阵行的内容决定哪些 LFSR 参与输出，输出又回填修改该行，形成闭环自修改。掩码的 bit 分布受乘性混合后的低 8 位驱动，非均匀随机。

### 3.3 面隔离跨步扩散

面 f 在 step t 被修改，step t+8 再次被修改，中间 7 步修改了其他 7 个面。这 7 个面的掩码读取 → LFSR 演化 → raw 值间接影响步骤 t+8 时面 f 的读取结果。

## 4. 统计检验

| 检验 | HLFSR V10-Idx | ChaCha20 |

## 5. 已知攻击

### 相关攻击
- 8 位掩码 → 平均 4.5 条 LFSR XOR → 单条 LFSR 输出不可分离
- 64×64 乘性混合消除字内位关联 (G3 0/32)
- 掩码由矩阵动态决定，攻击者无法将输出与固定 LFSR 子集关联

### 代数攻击
- 输出函数含乘法 (度 ≈ 32) + 矩阵反馈闭环
- 无已知低次逼近

### 区分攻击
- 16 MiB 与 ChaCha20 不可区分 (Golomb+NIST 全部通过)

### TMDTO
- 内部状态 1033 位，TMDTO > 2^256

## 6. 退化状态

### 全零矩阵
mask = 0 → 回退 LFSR[idx&7]。第一条回填即破坏全零状态。

### 全零 LFSR
Galois 全零自持。init 时检查 lfsr_seed 非全零。

### mask=0 攻击面
mask=0 概率 1/256。攻击者若构造全零矩阵可在第一步触发，但 idx&7 自然轮转使得即使连续 mask=0，选通的 LFSR 每步不同。无固定偏倚。

## 7. 总结

| 属性 | 评估 |
|------|------|
| 等效密钥安全 | 256 位 |
| 内部状态 | 1033 位 |
| 线性复杂度 | 远超 2^20 |
| 代数度 | ≈ 32 |
| 周期 | ≥ 2^64−1 |
| 区分攻击 | 不可区分于 ChaCha20 |
| 侧信道 | 常数时间缓解 |
